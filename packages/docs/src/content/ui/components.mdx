# Components

`@bilo-io/ui` ships generic, framework-agnostic primitives. Everything below is
rendered live by the installed library — this page imports from `@bilo-io/ui`
exactly the way your app would.

## The catalog

| Group | Components |
| --- | --- |
| Actions & forms | `Button`, `Input`, `Textarea`, `Select`, `StyledSelect`, `Slider`, `Switch`, `Tabs`, `Accordion`, `Collapse` |
| Surfaces | `Card`, `GradientGlow`, `ContextRing` |
| Data display | `AreaChart`, `RadialGauge`, `MetricDial` |
| Reading | `ReadingLayout`, `Prose`, `proseComponents`, `TableOfContents` |
| Backdrops | `NeuroCloudBackground` (the starfield behind this page), `DynamicBackground` |
| Security | `PasscodePad`, `PasscodeSetupDialog`, `PasscodeUnlockDialog` |
| Icons | `GithubIcon`, `DiscordIcon`, `GoogleIcon`, `LinearIcon`, `SlackIcon` |
| Utilities | `cn` (class merge), typed design tokens, `ThemeToggle` |
